# Review checklist (before showing)

Look at the rendered preview, not just the code.

- [ ] Text matches the request verbatim (accents, capitals, punctuation).
- [ ] No text overflows its box, plaque or button.
- [ ] Accents and diacritics do not collide with the line above (raise line height, or change the word if the user allows).
- [ ] Enough contrast between text and background; on busy photos, strengthen the darkening behind the text.
- [ ] Everything important sits inside the safe zone (stories: 250 px top and bottom).
- [ ] Margins and alignment match brand.md or the reference.
- [ ] Clear hierarchy: headline first, then subhead, then call to action.
- [ ] Logo in the right version (light or dark) and not distorted.
- [ ] Clearly named layers in the PSD or in Figma.
- [ ] If a fallback font was used in the preview, say so and give the real name.

When matching a reference, place both side by side in one image and check proportions (headline size relative to width, vertical position of the text block).
