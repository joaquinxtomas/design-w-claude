# Adobe connector: uses around the design

The connector prepares material before and multiplies the piece after. It does not design a piece from scratch or deliver layered PSDs.

| Moment | Example request | What it solves |
| --- | --- | --- |
| Before: photos | "Match the color of these 8 photos so they look like one shoot" | Consistent batch editing |
| Before: photos | "Remove the background from these 3 product photos" | Cutouts without opening Photoshop |
| Before: photos | "Expand this horizontal photo to 1080×1920" | Client photos that are not vertical |
| Before: fonts | "Recommend 3 Adobe Fonts serifs for a premium brand" | Real, licensed fonts (optional) |
| After: formats | "Adapt this story to a 1080×1350 post, a Reel cover and a LinkedIn banner" | Variants per channel |
| After: video | "Turn this horizontal video into a vertical Reel" | Reframing and short cuts |
| In bulk | "With this InDesign template and this spreadsheet, generate the 40 certificates" | Pieces from data |
| Delivery | "Make a PDF with the 5 proposals for the client" | Ready-to-send presentations |

Typical combined flow: raw client photos → the connector matches them and makes them vertical → design the piece (PSD or Figma) → the connector creates the versions for each channel.

Activation: claude.ai → Settings → Connectors → Adobe. Signing in with a Creative Cloud account unlocks more tools and saves work across sessions.
